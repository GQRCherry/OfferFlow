## GitHub 状态

- `main` 分支持续集成已经成功运行；
- 自定义“发布 GitHub Pages”工作流已经成功构建并部署 `dist/`；
- 仓库当前仍选择了 `Deploy from a branch`，GitHub 随后又把仓库源码根目录覆盖发布，因此线上入口虽然返回 200，但仍引用 `/src/main.tsx`，不能作为生产页面使用；
- 需要在 **Settings → Pages → Build and deployment → Source** 中切换为 **GitHub Actions**，随后重新运行“发布 GitHub Pages”工作流，再进行最终线上验收。
